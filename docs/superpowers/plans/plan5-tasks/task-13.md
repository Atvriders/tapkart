**Interfaces:**

- **Produces** — no exported symbol. §16's census is unchanged by this task. What it produces for later tasks to read is a set of **Gradle properties**, and those names are a contract:

  ```properties

  tapkartKotlinPluginVersion    # the org.jetbrains.kotlin.android version, RESOLVED once
  ```

  and one Gradle task, `:app:printTapkartPins`, whose output is the machine-readable form of §6.6's table:

  ```
  applicationId=<value>
  namespace=<value>
  compileSdk=<int>
  minSdk=<int>
  targetSdk=<int>
  android16ApiLevel=<int>
  ```

  Task 14's manifest assertions and the `android` CI job both read that task's output; nothing parses `gradle.properties` directly.

**F-P5-31, and why this task contains no version number.** *"Neither draft could verify these and neither should invent them."* Contract §0 says the same thing in general terms: *"Invented numbers — forbidden where a published table or a template already carries the number. §6.6 (Android/Capacitor) and §5.9 (QR) both work this way: the contract fixes the **rule and the format**, the implementing task **reads and records the value**."*

So every number below arrives from a command, not from prose:

| Pin | The rule (§6.6) | Where the value comes from |
|---|---|---|
| Capacitor major | pinned in `apps/android/package.json` | `npm install @capacitor/core@latest` writes the caret range npm resolved |
| AGP, Gradle wrapper | from that Capacitor version's template, **unmodified** | the generated `build.gradle` and `gradle/wrapper/gradle-wrapper.properties` |
| Kotlin plugin | from that version's template if it declares one; otherwise resolved once and recorded | Step 4's `maven-metadata.xml` query |
| `targetSdk` | **≥ the Android 16 API level** | `maxOf(template targetSdk, tapkartAndroid16ApiLevel)`, computed in `build.gradle.kts` |
| `compileSdk` | **`= targetSdk`** | the same expression, assigned to both |
| `minSdk` | **`max(Capacitor's floor, 26)`** | `maxOf(variables.gradle's minSdkVersion, 26)` |
| JDK | 21 in CI | the CI task's `setup-java`; nothing here pins it |

**The three sdk pins are expressions, not literals, and that is the point.** §12.2 assertion 25 asserts *relations* — `compileSdk == targetSdk`, `targetSdk >= <recorded Android 16 API level>`, `minSdk >= 26` — because *"a relation survives an SDK bump; a hardcoded number becomes a lie the day the template moves."* Writing the relations into `build.gradle.kts` makes them true by construction; `assert-pins.sh` still checks them, because an expression can be edited.

**What this task cannot prove, stated before the steps rather than after.** A Gradle configuration, a wrapper and a generated manifest have **no meaningful failing test**. There is no assertion to write that fails for the right reason before `cap add android` runs and passes after it, and faking one — a test that greps for a file, run before the file exists — proves only that a file exists. So the Android half of this task is verified by **running the artifact**: Gradle configures, Gradle builds, and the pins script reads the values back out of the configured project rather than out of the file that set them.

§1's guard, on the other hand, **is** testable, and it is testable in the strongest way available: by planting exactly the material it exists to catch and watching it fail. That is Step 1 and Step 2, and it is a real RED.

- [ ] **Step 1: Write the failing test**

Create `packages/invite/test/no-secrets.test.ts` — contract §1 guard 1, and §12.2's assertion 14:

```ts
import { execFileSync } from 'node:child_process'
import { readFileSync } from 'node:fs'
import { fileURLToPath } from 'node:url'
import { describe, expect, it } from 'vitest'

/** The repository root: this file is at <root>/packages/invite/test/. */
const REPO_ROOT = fileURLToPath(new URL('../../..', import.meta.url))

/** A floor on the number of files actually scanned.
 *
 *  Contract §1: "If `git ls-files` cannot be run it fails the test — a
 *  repo-reading test that silently passes when it cannot read the repo is this
 *  project's signature defect wearing a hat." The same defect has a quieter
 *  form: an enumeration that returns two files, or only binaries, and reports
 *  success. This floor is what makes the scan's SIZE part of the assertion. */
const MIN_SCANNED_FILES = 20

/** A PEM block header. The trailing dashes are required, so a document that
 *  merely writes the words does not trip the guard that protects it. */
const PEM_HEADER = /-----BEGIN [A-Z0-9 ]+-----/

/** A COMPLETE dotted quad inside 10/8, 172.16/12 or 192.168/16, and never one
 *  followed by a `/`. §1: "never a bare prefix, so that a document *describing*
 *  the rule does not trip it" — and `10.0.0.0/8` in a sentence about the rule is
 *  exactly that document. RFC 5737's ranges (192.0.2, 198.51.100, 203.0.113)
 *  and 127.0.0.1 are permitted by §1 and match nothing here. */
const RFC1918 =
  /(^|[^0-9.])(10\.\d{1,3}\.\d{1,3}\.\d{1,3}|192\.168\.\d{1,3}\.\d{1,3}|172\.(?:1[6-9]|2\d|3[01])\.\d{1,3}\.\d{1,3})(?![0-9./])/

/** 32 colon-separated hex byte pairs: the shape of a SHA-256 certificate
 *  fingerprint, and 95 characters exactly. */
const COLON_HEX_32 = /(?:[0-9A-Fa-f]{2}:){31}[0-9A-Fa-f]{2}/g

/** §1 permits exactly one fingerprint in a repo file: 32 obviously-fake bytes.
 *  A hit is allowed only when EVERY byte is drawn from that placeholder's four
 *  values, which admits the rotation `applinks.test.ts` uses as its second
 *  format-valid placeholder and admits nothing a real keytool ever printed. */
const FAKE_BYTES = new Set(['DE', 'AD', 'BE', 'EF'])

function isObviouslyFakeFingerprint(hit: string): boolean {
  return hit.split(':').every((b) => FAKE_BYTES.has(b.toUpperCase()))
}

const KEYSTORE_EXTENSIONS = ['.jks', '.keystore', '.p12']

function trackedFiles(): string[] {
  // -z, because a path may contain anything a filesystem allows.
  const out = execFileSync('git', ['ls-files', '-z'], {
    cwd: REPO_ROOT,
    encoding: 'utf8',
    maxBuffer: 64 * 1024 * 1024,
  })
  return out.split('\0').filter((p) => p.length > 0)
}

/** A committed binary — the Gradle wrapper jar is one — is scanned for none of
 *  the text rules, because a byte sequence in a zip is not a secret and a false
 *  positive there would get this whole test deleted. The keystore-extension rule
 *  above is what covers binaries, and it works on the NAME. */
function isBinary(bytes: Buffer): boolean {
  const head = bytes.subarray(0, 8192)
  return head.includes(0)
}

describe('contract §1: nothing secret, real or private is in this repository', () => {
  it('can enumerate the repository, or fails', () => {
    let files: string[] = []
    expect(() => {
      files = trackedFiles()
    }).not.toThrow()
    expect(files.length).toBeGreaterThanOrEqual(MIN_SCANNED_FILES)
  })

  it('tracks no keystore, in any of its three spellings', () => {
    const offenders = trackedFiles().filter((p) =>
      KEYSTORE_EXTENSIONS.some((ext) => p.toLowerCase().endsWith(ext)),
    )
    expect(offenders).toEqual([])
  })

  it('carries no PEM block, no RFC1918 address, and no fingerprint but the placeholder', () => {
    const files = trackedFiles()
    const problems: string[] = []
    let scanned = 0

    for (const rel of files) {
      let bytes: Buffer
      try {
        bytes = readFileSync(new URL(rel, new URL(REPO_ROOT, 'file:')))
      } catch {
        // A tracked path that is not readable (a submodule gitlink, a deleted
        // file in a dirty tree) is not evidence of a secret. It is also not
        // evidence of safety, so it is not counted as scanned.
        continue
      }
      if (isBinary(bytes)) continue
      scanned++

      const text = bytes.toString('utf8')
      const lines = text.split('\n')
      for (let i = 0; i < lines.length; i++) {
        const line = lines[i]
        if (PEM_HEADER.test(line)) {
          problems.push(`${rel}:${i + 1}: a PEM block header`)
        }
        const lan = RFC1918.exec(line)
        if (lan !== null) {
          problems.push(`${rel}:${i + 1}: an RFC1918 address (${lan[2]})`)
        }
        const hits = line.match(COLON_HEX_32)
        if (hits !== null) {
          for (const hit of hits) {
            if (!isObviouslyFakeFingerprint(hit)) {
              problems.push(`${rel}:${i + 1}: a certificate fingerprint that is not §1's placeholder`)
            }
          }
        }
      }
    }

    expect(scanned).toBeGreaterThanOrEqual(MIN_SCANNED_FILES)
    expect(problems).toEqual([])
  })
})
```

**5d.** Create `apps/android/scripts/assert-pins.sh` — §12.2 assertion 25:

```bash
#!/usr/bin/env bash
#
# §6.6's pins, asserted as RELATIONS over the CONFIGURED project.
#
# Run:  bash apps/android/scripts/assert-pins.sh
#
# Run it AFTER `:app:assembleDebug` at least once: AGP downloads the compileSdk
# platform, which is what lets check 4 cross-check the recorded Android 16 API
# level against the SDK instead of trusting the number in gradle.properties.
set -euo pipefail

script_dir="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
android_dir="$(cd "$script_dir/.." && pwd)"

fail() {
  echo "FAIL: $*" >&2
  exit 1
}

pins="$("$android_dir/gradlew" -p "$android_dir" -q :app:printTapkartPins)"
get() {
  local key="$1" value
  value="$(printf '%s\n' "$pins" | sed -n "s/^$key=//p" | head -1)"
  [ -n "$value" ] || fail "printTapkartPins emitted no '$key'. Output was:
$pins"
  printf '%s' "$value"
}

application_id="$(get applicationId)"
namespace="$(get namespace)"
compile_sdk="$(get compileSdk)"
min_sdk="$(get minSdk)"
target_sdk="$(get targetSdk)"
android16="$(get android16ApiLevel)"

echo "== 1. compileSdk == targetSdk =="
[ "$compile_sdk" = "$target_sdk" ] ||
  fail "compileSdk ($compile_sdk) != targetSdk ($target_sdk) — §6.6"

echo "== 2. targetSdk >= the Android 16 API level =="
[ "$target_sdk" -ge "$android16" ] ||
  fail "targetSdk ($target_sdk) is below the Android 16 API level ($android16).
  Spec §2's entire argument is about Android 16 behaviour; a lower target opts out of it."

echo "== 3. minSdk >= 26 =="
[ "$min_sdk" -ge 26 ] ||
  fail "minSdk ($min_sdk) is below 26 — §6.6: picking it too low silently ships to
  devices nothing was tested on."

echo "== 4. the recorded Android 16 API level still matches the SDK =="
sdk_root="${ANDROID_HOME:-${ANDROID_SDK_ROOT:-}}"
[ -n "$sdk_root" ] || fail "neither ANDROID_HOME nor ANDROID_SDK_ROOT is set"
found=""
for p in "$sdk_root"/platforms/*/source.properties; do
  [ -f "$p" ] || continue
  ver="$(sed -n 's/^Platform\.Version=//p' "$p")"
  api="$(sed -n 's/^AndroidVersion\.ApiLevel=//p' "$p")"
  case "$ver" in
    16|16.*) found="$api" ;;
  esac
done
[ -n "$found" ] || fail "no installed platform declares Platform.Version=16, so the
  recorded tapkartAndroid16ApiLevel ($android16) could not be cross-checked.
  Run './gradlew -p apps/android :app:assembleDebug' first — AGP downloads the
  compileSdk platform — then run this script again."
[ "$found" = "$android16" ] ||
  fail "gradle.properties records tapkartAndroid16ApiLevel=$android16, but the installed
  Android 16 platform is API $found. One of the two is stale."

echo "== 5. namespace == applicationId, and it is §1's value =="
[ "$namespace" = "$application_id" ] ||
  fail "namespace ($namespace) != applicationId ($application_id) — §6.1"
[ "$application_id" = "io.github.atvriders.tapkart" ] ||
  fail "applicationId is '$application_id', not §1's 'io.github.atvriders.tapkart'.
  §3 value 4 requires it to equal TAPKART_ANDROID_PACKAGE in the deployment."

echo "OK: compileSdk=$compile_sdk targetSdk=$target_sdk minSdk=$min_sdk android16=$android16"
```
